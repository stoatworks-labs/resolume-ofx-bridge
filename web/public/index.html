Wrap a plugin, in your browser

Turn an FFGL plugin (Resolume) or an After Effects plugin into an OpenFX plugin for DaVinci Resolve, Vegas, Nuke and Natron. Everything happens on your own machine — your plugin is never uploaded anywhere, and there is nothing to install to do it.

This browser can't do it

Assembling a plugin bundle needs the File System Access API, which today means Chrome or Edge on a desktop. Safari and Firefox can't write folders from a page. Use the desktop build instead — link at the bottom.

1

Choose the plugin to wrap

A .bundle (FFGL) or .plugin (After Effects) folder.
2

Choose where it goes

Pick any folder — your Downloads is fine. macOS won't let a browser write straight into /Library/OFX/Plugins, so you'll move it there with the command below.
3

Build it

Now install it. macOS quarantines everything a browser writes, and a quarantined plugin does not load at all — the host reports a code-signature policy error, or just never lists it. Clearing the flag is not optional:

What this page can't do

    

      This is a file copier. It assembles a bundle and hands it to you — it never runs
      your plugin, because a browser cannot execute native code. That has consequences
      worth knowing before you rely on it:
    

    
    
      
  • 
        It cannot tell you whether your plugin will work. The desktop build loads
        each plugin and reports the real reason it can't be wrapped — an effect that
        needs a GPU suite, an After Effects plugin wanting services this bridge doesn't
        provide, a plugin with no filter context. Here, that same plugin builds happily
        and then simply doesn't appear in your host, with nothing to explain why.
      
    • 
      
  • 
        Chrome or Edge, on a desktop, only. No other browser can write a folder.
      
    • 
      
  • 
        macOS, Apple Silicon and Intel. Windows and Linux shells aren't built yet.
      
    • 
      
  • 
        You still need one Terminal command. Everything a browser writes is
        quarantined, and a quarantined plugin is refused by macOS at load — measured,
        not assumed. No browser API can clear it, so the xattr line above
        is a required step, not a suggestion.
      
    • 
      
  • 
        The wrapped plugin carries the usual crossing costs — FFGL guests render at
        8 bits per channel and one frame at a time, and an effect that keeps its own
        clock will behave oddly when the host scrubs.
      
    •
